Rejoins l’académie

Pour nos premiers membres, utilise ton compte GitHub. Ton profil Dragonballogie sera créé automatiquement lors de ta première connexion.

Aucun accès à tes dépôts GitHub n’est demandé par Dragonballogie. L’adresse e-mail de ton compte reste privée. Les nouveaux comptes commencent comme membres.

Inscription classique par e-mail : à venir.

Utilisation de tes données

La connexion utilise GitHub et Supabase. Ton identifiant, ton adresse e-mail, ton pseudo, ta biographie, tes spécialités et ton rôle sont utilisés pour gérer ton compte. Les profils ne sont pas publics ; le fondateur et les administrateurs peuvent consulter les pseudos, rôles et dates d’inscription pour gérer l’équipe. Les changements de rôle sont journalisés. Les contributions soumises sont consultables par la direction pour validation. Pour demander la correction ou la suppression de ton compte, contacte le fondateur via le Discord du site. Cette version bêta ne propose pas encore toutes les fonctionnalités de gestion de compte.
