# Banque d'images de décors

Images servant à habiller le site (fonds de pages, bandeaux, salons de l'Univers). Un dossier par univers, nommé comme l'identifiant de `assets/univers.js`.

- `capsule/` : Capsule Corp
- `gero/` : laboratoire du Dr Gero
- `kaioshin/` : Kaiô Shinkai, le monde des Kaiô Shin
- `namek/` : Namek (l'image actuelle est dans `images/univers/namek.webp`)

## Ajouter une image
1. La déposer dans le dossier de son univers, en `.webp`, nommée `lieu-sujet-NN.webp` (ex. `capsule-corp-dome-02.webp`).
2. Ajouter une entrée dans `decors.json` (description, format, usage conseillé, statut des droits).
3. Noter dans `utilise_dans` où elle sert, une fois utilisée.

## À savoir
- Préférer des **fonds sans personnage** pour les pages ; les captures avec personnages servent plutôt aux articles.
- Toutes les images sont à **droits à vérifier** tant que leur source n'est pas documentée ; les remplacer par des versions HD ou originales avant une mise en avant durable.
- Éviter les images portant un filigrane.
